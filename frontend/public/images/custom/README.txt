DRAVON IMAGE REPLACEMENT

Replace these files with your own images, keeping the exact filenames:
- hero.webp      Homepage hero background
- loader.webp    Full-screen loading screen background
- about.webp     About/story section image (available for use in code)
- community.webp Community/story image (available for use in code)

Recommended: WebP or JPG, landscape 16:9, 1600px wide or larger.
To use a different filename/path, edit frontend/lib/site-images.ts.

Skill images are in ../skills/. Replace each named file with the matching skill photo.
